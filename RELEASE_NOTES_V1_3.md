# V1.3 — Evidence Threads · Release Candidate

This release focuses on **explanatory accuracy inside the high-fidelity radial hero**, rather than adding more decorative complexity.

## Improvements
1. Added nine carefully typed, source-bounded research links across the original eight conceptual nodes.
2. Each scroll-stage network state activates only 1–4 relevant relationships; one is foregrounded.
3. Added `Next link` progression and a concise evidence-specific explanation in the sticky story stage.
4. Added a separate, selectable relationship list in the full Explore Constellation with an accompanying study citation or explicit evidence-gap explanation.
5. Preserved keyboard-operable nodes and links, node isolation, reduced-motion preferences, all 15 scrollytelling checkpoints, colour semantics, Guided/Explore modes, Signal Plate, language evaluation, geography and methods drawers.
6. Published machine-readable relationship definitions and a clear visual semantics contract.

## Intentional non-changes
- No new measured data, invented cross-study combined values, geographic routes, or unsupported causal claims.
- 416 decorative filaments remain explicitly non-data.
- The scientifically separate supporting instruments retain their measurement boundaries.

## QA
A targeted functional suite ran in desktop 1440×900, tablet 920×850, mobile 390×780 and small-mobile 360×720 Chromium emulation. Additional all-checkpoint, source and methods tests passed with no detected JavaScript exceptions. This is a **candidate**, not formal publication certification.
